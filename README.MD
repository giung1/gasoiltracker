# GasoilTracker

### Build Requirements:
- Java 17 or higher
- Maven 3.6+
- JavaFX 21.0.7

### How to Build:
```bash
mvn clean compile
mvn package
```

### How to Run:
```bash
java -jar target/gasoiltracker.jar
```

The application now features a modern, professional interface that provides an excellent user experience while maintaining all existing functionality.
